# 饮料配置

> 本文件由 [内容文档生成器](../scripts/generate-content-docs.mjs)读取当前源码生成。规则版本 19，存档版本 5。

先抽基础 **2%** 的稀有款；未中稀有时，理想配方默认 **80%** 出目标，只有一个合法候选时普通分支自然为100%。偏离理想配方后概率平滑变化；益生菌对所有合法组合的普通主结果都稳定至 **100%**。通常的理想配方与益生菌整局概率分别为 **78.4% / 98%**。

添加剂最多 1 种，也可不加。稀有功能剂给对应款合计增加 3% 的概率，使当轮稀有合计为 **5%**；因为不能与益生菌同选，此时多候选理想配方每轮实际目标概率为 **76%**。

完整规则见 [便便产出算法说明](便便产出算法说明.md)，46 条普通款配方见 [固定配方表](固定配方表.md)。

## 饮料负责什么

单选一种饮料，原来的饮用量拉条就是全部水分摄入：250–2500 mL，每档 250 mL，默认 1500 mL。选牛奶 1500 mL，就按牛奶 1500 mL 计算；选择清水时也使用同一拉条。

饮用量直接影响湿软指数，饮料湿软偏置乘 min(水量/1500, 5/3)；气泡与饮料染色也随这一饮用量增强并封顶。饮用量与阶段进入普通配方相似度，不改变稀有预算。颜色先从真实食材、饮料与添加剂计算主色，再过滤颜色身份，抽中图鉴不再强制改色。

# 便便产出算法说明

当前规则版本 **17**，依据 [新配方设计原稿](新配方设计原稿.md) 实施。以用户后续确认覆盖原稿：**明天见喷射保留第 7 型、原名、配图和原食物＋饮料＋力度组合**。益生菌继续使用原有 80% → 100% 普通分支规则。

## 一轮的计算顺序

1. 选择 1–3 种食物、一种饮料及饮用量、最多一种添加剂、消化阶段 T。
2. 阶段选随机时，在开始时等概率抽取 2 / 4 / 8，锁定并保存。开始前预告为三档最终池的等权混合；开始后用锁定阶段。
3. 点击停止锁定力度。力度不进入湿软指数，不把干硬物态变成水样。
4. 按完整配方与湿软指数构建同一个最终分布。先抽稀有；未中时抽普通目标或同型自由候选。锁定后约 400 ms 揭晓，消化阶段不增加等待。
5. 保存实际饮用量、阶段、力度与本次个体；刷新不会重抽阶段或结果。首次发现的个体也保存这份实际配方。

## 水量与湿软指数

原来的饮用量拉条直接表示所选饮料的全部水分摄入：**250–2500 mL，每档 250 mL，默认 1500 mL**。例如选牛奶并拉到 1500 mL，就是本轮喝牛奶 1500 mL。选择清水也使用同一拉条。保存字段 `water` 现在就是这一饮用量。

```text
食物湿软值 = (4 − 食物当前软硬值) × 0.9 + 食材质地偏置
食物权重 = 当前影响强度 × (主食 ? 2 : 1)
foodBase = 按上述权重合并食物湿软值
waterBonus = clamp((饮用量 − 1300) / 1000, −1.1, +1.0)
drinkBonus = 饮料湿软偏置 × min(饮用量 / 1500, 5/3)
timeBonus = {2: +0.75, 4: 0, 8: −0.85}
additiveBonus = −添加剂软硬修正 × 0.5
S = foodBase + waterBonus + drinkBonus + timeBonus + additiveBonus
```

| S 区间 | 基础物态 |
| --- | --- |
| S ≤ −2.30 | 1 型颗粒硬块 |
| −2.30 < S ≤ −1.45 | 2 型结块条 |
| −1.45 < S ≤ −0.55 | 3 型裂纹条 |
| −0.55 < S ≤ 0.55 | 4 型柔软条 |
| 0.55 < S ≤ 1.30 | 5 型完整软块 |
| 1.30 < S ≤ 2.20 | 6 型糊状 |
| S > 2.20 | 7 型水样 |

食材质地偏置在 src/content/food-wetness.js；它使九项参数里同为软硬 4 的白吐司与米饭仍有干湿差别。**没有改写用户的 food-attribute-values.js**。现有软硬旋钮、影响强度变化会直接进入上式，凝聚、延展、颗粒与蓬松仍参与型内造型。熟甜菜根和蒸土豆的初始参数单独定义。

饮料偏置、食品质地偏置为游戏校准值，未照搬原稿中的临时食物分数。固定配方表的 S 列由真实代码生成；当前 46 个普通中心和 10 个稀有主题基底都已核验分类。食品或饮料调参后，应重新核验，不沿用旧分数。

## 固定配方与益生菌

46 款普通及特别便便各有唯一完整配方：**食物集合、饮料种类、饮用量、消化阶段、力度区间**。食物顺序不影响匹配。还必须符合该款物态；不能用过期配方把调参后已变干的食物强行变成喷泉。

- 无益生菌：未中稀有时目标占普通分支 **80%**，默认整局目标 **78.4%**。
- 唯一添加剂为益生菌：未中稀有时匹配目标占普通分支 **100%**，默认整局 **98%**。
- 不匹配完整配方时，益生菌不承诺固定品种；仍按当前物态与距离分配。
- 闪粉派对需闪粉，碎金芝麻卷需金箔，银霜斑点卷需银霜，闪粉银河需闪粉。固定目标和自由池都检查材料。这四款不能再加益生菌；金箔款在 5% 稀有预算下整局目标为 76%。
- 马桶仅影响外观与评分，不影响上述概率。

## 自由组合与偏离

先按 S 确定普通物态，再只在同型、且满足装饰材料的普通模板中分配。完整中心保留明确的 80% / 100%；没有命中、或进入剩余 20% 分支时，按下列距离分配：

```text
距离 = 0.5 × |饮用量 − 配方饮用量| / 250
     + |阶段湿软修正之差|
     + (饮料不同 ? 1 : 0)
     + 2 × 力度档位距离
     + 4 × (1 − 食物交集数量 / 食物并集数量)
     + 0.15 × 凝聚、延展、颗粒、蓬松的绝对差之和
权重 = 1 / (1 + 距离)^3
概率 = 各模板权重归一化
```

同型候选都有正权重，不再截断到最近三款。饮用量 只差一格、仍处同一物态时，原目标保留按距离计算的机会；跨过 S 的类型阈值后，普通产出随物态切换。力度只调整这一型内部的模板接近程度。所有预告、后台、条件查看与实际抽取共用 src/game/outcome-pool.js。

## 稀有与主题配方

10 款稀有每轮基础各 0.2%，合计 **2%**，不设食物、水量、阶段或力度门槛。稀有功能剂给其目标合计增加 **3 个百分点**，稀有总量为 **5%**；多个目标平均分摊。

稀有主题搭配只帮助理解其基础物态，不是 80% / 100% 稀有固定配方，也不提高概率。金属、晶体、虹彩等保留自身固定形态，可以超出普通物态，以独立变异解释。

## 外观与时间

同一饮用量同时调节水分摄入、饮料湿软特效、气孔与饮料染色强度，特效有上限。短阶段增加残留、长阶段减少，金针菇细丝在长阶段仍保持可见。颜色和表面装饰不改变已抽中的 ID；水样液体的气孔不会将其换成实体软块。

2 / 4 / 8 为游戏阶段，不是现实消化时长；所有阈值和容量是游戏参数。固定配方和实际分数见 [固定配方表](固定配方表.md)。

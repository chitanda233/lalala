# 便便产出算法说明

规则版本 **24**。食物、所选饮料及饮用量、添加剂决定物态与来源身份；力度继续影响同身份内造型。消化时间入口、计算和新单局字段已移除。保留56款图鉴、46普通与10稀有。

## 为什么改为组合规则

过去每款只有一条精确配方，再围绕这条配方分配概率。玩家随意搭配时，食材明明合理，却可能因为食物ID、消化或力度不匹配而得到很弱的反馈。

现在配方是可行示例。食材提供主题与质地，饮用量控制软硬，添加剂提供功能、装饰或稀有增益，力度调整同身份内造型。型内倾向比较食物品类、标签和实际结构属性，不比较完整食物清单是否相等，也没有精确命中80%的额外奖励。同类替换、增加配菜和没有列入推荐表的组合都使用同一套规则。

## 一轮的顺序

1. 选择1–3种食物、一种饮料、0–1250 mL饮用量和至多一种添加剂。
2. 点击开始启动力度指针，再点击停止锁定力度；先按当前食饮与添加剂计算物态、来源与身份预算，再用力度调整身份内的造型概率。
3. 普通与稀有合成一个归一化池，只抽一次结果；另一个随机数生成表面种子，约400 ms后揭晓。
4. 保存实际配方与完整外观。已发现收藏保留原快照，不按当前规则重新抽取。

主界面仍只展示输入与操作，不提前显示预测品种、分型或概率。图鉴和后台可主动查看指定目标概率与当前主结果；两者可能不同，必须分别展示。

## 单一饮用量与物态

滑条表示所选饮料的全部摄入量，范围0–1250 mL，每档250，默认750。没有额外清水字段。0 mL不计饮料的染色、标签、气泡、湿软偏置和顺畅加成。

```text
食物湿软值 = (4 − 食品软硬值) × 0.9 + 食材偏置
食物权重 = 影响强度 × (主食 ? 2 : 1)
foodBase = 食物湿软值的加权平均
waterBonus = clamp((饮用量 − 1000) / 500, −2, +0.5)
drinkScale = min(饮用量 / 1500, 5/3)
drinkBonus = 饮料湿软偏置 × drinkScale
additiveBonus = functional ? −添加剂软硬修正 × 0.5 : 0
S = foodBase + waterBonus + drinkBonus + additiveBonus
```

水量现在承担原时间档位的一部分调节空间：0 mL修正−2，默认750修正−0.5，1250修正+0.5。没有时间修正、隐藏联动或物态随机微扰；用户已有食品九项参数保持原样。

| S区间 | 普通物态 |
| --- | --- |
| ≤−2.30 | 1型硬颗粒 |
| −2.30～−1.45 | 2型结块条 |
| −1.45～−0.55 | 3型裂纹条 |
| −0.55～0.55 | 4型柔软条 |
| 0.55～1.30 | 5型完整软块 |
| 1.30～2.20 | 6型糊状 |
| >2.20 | 7型水样 |

除首行外，下界不包含，上界包含。46条普通示例均满足目标物态与来源。明天见喷射仍为汉堡＋金针菇、鲜牛奶1250 mL、强力度、第7型。10条稀有主题只作展示，不受普通物态资格限制。

## 真实来源与候选

每款普通图鉴有独立的来源条件，推荐食材不能自动变成必需食材：

- `sources.foods`：实际食物必须全部存在，例如金针菇、玉米、燕麦。
- `sources.tags`：当前食物、有效饮料或添加剂提供对应标签，例如花瓣、跳跳颗粒、全谷物。
- `sources.pigment`：必须匹配当前真实主色，抽中品种不能凭空改色。
- `sources.additives`：必须选择对应装饰剂，受最多一种限制。
- `identity`：把同来源身份的多个造型放在一组；`base`标记通用基础造型。

先排除来源不符或普通物态不符的候选。默认每型都有无来源门槛的基础候选。手工编辑可以改变来源或推荐搭配，后台只提示不一致，不阻止保存；如果实际没有合法普通候选，预览报错，游戏不发放非法结果。

`generation.forceZone`保存造型偏好力度；推荐配方保留`forceZone`区间，去掉消化字段。它是概率倾向，不是未满足就失败的开关。

## 食材主题与造型变化

合法候选按来源身份分组，并区分有真实来源条件的主题组与无来源门槛的通用组：

1. 同时存在主题与通用候选时，主题合计占普通分支 **70%**，通用合计 **30%**。例如实际吃了金针菇且物态合适，金针菇主题会明显更容易出现。
2. 没有可用主题时，通用造型分享全部普通预算；只有主题时，主题分享全部预算。只有一个合法候选时自然100%，不插入非法品种凑数。
3. 同一类的身份组之间，以及同身份的造型之间，各将 **25%均匀分配**、**75%按倾向权重分配**。因此偏离推荐的组合依然有变化，每个合法候选都保留正概率。

主题预算、变化保底分别读取 `ordinaryThemeShare` 和 `ordinaryVarietyShare`。70%与25%都是普通分支内比例，须再乘本轮普通总预算；不能把两者相加理解为整局概率。

### 倾向如何计算

示例食材先按影响强度合并为品类与标签分布，主食权重乘2；每份食物的标签均分其自身权重。当前餐盘同样计算。两个分布的重合度取各项较小占比之和：

```text
食材倾向 = 0.6 × 品类重合度 + 0.4 × 标签重合度
结构偏差 = 当前五项结构与图鉴五项结构的平均绝对差
基础权重 = exp(2 × 食材倾向 − 结构偏差 / 1.5)
力度距离 = 到造型偏好区间的距离 / 33
组内造型权重 = 基础权重 × exp(−1.5 × 力度距离)
```

五项结构为软硬、凝聚、延展、颗粒、蓬松；当前软硬由S计算，其余来自食物属性、饮料气泡与明确启用的功能添加剂。品类或标签相同的替代食材没有额外ID惩罚，真正不同的质地、主色或来源仍会改变结果。

身份组权重取组内最高基础权重，不读取力度、不按造型数量累加，避免增加造型或调整力度就扩大主题预算。力度只参与组内造型分配，偏好区间外平滑衰减；轻力度更容易出现轻柔造型，强力度更容易出现高力度造型。最终普通概率最高者是确定主结果，同概率按稳定ID排序，不读取上一轮历史。

## 益生菌与稀有

益生菌将当前合法主结果稳定为普通分支100%；不会把图鉴中指定的任意目标变为主结果。无关联稀有组时整局为98%，其余2%仍可能出稀有。需要其他装饰剂的品种不能同时使用益生菌。

没有关联组时，全体稀有均分基础2%；所选添加剂存在有效关联组时，仅组内均分20%，组外为0，普通预算80%。不叠加基础2%，不另抽第二次稀有。关联预算读取每款添加剂的配置，不写死品种、组数或当前稀有数量。稀有始终保留各自固定造型，没有主题原料、时间或力度门槛。

| 情况 | 普通预算 | 稀有预算 |
| --- | ---: | ---: |
| 无关联添加剂组 | 98% | 全体均分2% |
| 有有效关联组 | 80% | 仅组内均分20% |
| 益生菌（当前默认配置） | 主结果98% | 全体均分2% |

## 表面效果与校验

只有`functional`开启的添加剂修正参与物态与结构倾向。装饰、材质特效和关联稀有组独立配置；未启用功能的修正只作用于表面。鲜牛奶湿软偏置+0.50，牛奶与辣酱没有隐藏联动。

残留只来自当前食材及其保留度；消化时间不再增减残留。金针菇印记要求真实选择金针菇。外观种子固定纹理位置和数量，不旋转主体、不占新收藏条目。

后台、图鉴、条件查看与实际抽取共用 `outcome-pool.js`。本次定向回归覆盖无时间输入、46例可达、主题预算、自由替换、多样保底、力度改变组内造型但不改身份预算、来源过滤、益生菌与预览／抽取一致。完整示例和实际目标概率见 [推荐配方表](固定配方表.md)。

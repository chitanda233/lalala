# 便便产出算法说明

更新日期：2026-10-18。规则版本：15。本次按用户要求重构：固定配方让普通款可以定向获得，稀有款每次都有独立、明确的概率预算。食物效果属于游戏设定。

## 一眼看懂规则

每款普通便便都有一条固定配方：**食物组合＋一种饮料＋力度区间**。食物的选择顺序不影响匹配。每轮先抽 **2% 稀有**；没有抽中稀有且命中固定配方时，再以 **80%** 概率产出目标普通款。选择益生菌后，这个普通分支的目标概率提高到 **100%**。

| 本轮情况 | 固定配方目标的总体概率 | 其他普通款合计 | 稀有款合计 |
| --- | ---: | ---: | ---: |
| 命中固定配方，不加添加剂 | 78.4% | 19.6% | 2% |
| 命中固定配方，选择益生菌 | 98% | 0% | 2% |
| 命中固定配方，选择稀有功能剂 | 76% | 19% | 5% |
| 没有命中固定配方，无稀有加成 | — | 98% | 2% |
| 没有命中固定配方，一个稀有功能剂 | — | 95% | 5% |

80% 是**未抽中稀有时的条件概率**，所以固定配方目标的总体概率为 `98% × 80% = 78.4%`。益生菌是可选的稳定剂，不是配方的必要原料。最多只选一种添加剂：益生菌与其他功能剂不能同时选。

本轮保留 **56 款**：46 款普通款（包括 `common` 和 `uncommon`）、10 款稀有款（`special`）。完整定向组合见 [固定配方表](固定配方表.md)。

## 一、哪些输入负责什么

| 输入 | 作用 |
| --- | --- |
| 主食/食物，1～3 种 | 主导基础形态，保留食物属性与可见食材印记 |
| 饮料，1 种 | 主要影响软硬物态和颜色 |
| 添加剂，0～1 种 | 益生菌把匹配配方的普通分支稳定为 100%；其他功能剂稳定物态、叠加装饰，或增加对应稀有款的明确概率 |
| 力度，0～100 | 匹配轻、中、强三档固定配方；不再另套复杂倍率 |
| 饮用量 | 仅对自由组合和普通落空结果的软硬作最多 ±1 修正，不影响固定配方命中 |
| 消化时间 | 保留 2 / 4 / 8 / 随机作为过程设置，不改变产出概率 |
| 马桶 | 负责装备外观与评分反馈，不改变产出概率 |

本次规则覆盖旧的消化时间形态偏移、马桶稀有倍率、来源资格门槛和多层指数权重。它们不再暗中改变目标款概率。

## 二、统一的五项形态属性

每款便便都明确保存五项 1～7 的形态属性；稀有款也有自己的固定形态，不用普通款临时套材质冒充一个稀有品种。

| 属性 | 字段 | 数值方向 |
| --- | --- | --- |
| 软硬 | `hardness` | 1 液软，7 干硬 |
| 凝聚 | `cohesion` | 1 分散，7 聚合成整体 |
| 延展 | `elongation` | 1 短小，7 修长、盘卷 |
| 颗粒 | `grain` | 1 细腻，7 粗颗粒 |
| 蓬松 | `porosity` | 1 紧实，7 多孔、蓬松 |

食品原有的可编辑字段 `softness` 继续沿用，方向仍是 **1 软、7 硬**；规则中把它当作食物硬度使用，不反转用户已有调参数值。

多种食物按原有“影响强度”合并属性，主食谷物的权重再乘 2，让主食对餐盘形态起更大作用：

```text
食物权重 = 影响强度 × 主食系数（主食谷物为 2，其他为 1）
食物属性平均 = Σ（该食物属性 × 食物权重）/ Σ 食物权重
自由组合基础硬度 = 食物硬度 × 70% + 饮料硬度 × 30%
```

凝聚、延展、颗粒、蓬松主要读取食品原有属性；气泡类饮料可给蓬松加 1。自由组合与固定配方的普通落空分支只挑最接近的 3 款，按属性和食饮配方的接近程度分配对应预算；已锁定的固定配方目标不参加这次重新竞争。

颜色、食材保留度、染色能力、顺滑度继续分别用于外观或评分，不再叠成一串隐藏的形态和稀有倍率。

## 三、固定配方怎样匹配

每条配方记录目标便便、食物 ID 集合、饮料 ID 和力度档位。

必须同时满足：

1. 食物集合完全相同：不看摆放顺序，不能少一项或多一项。
2. 饮料完全相同。
3. 力度落在指定区间：轻力度 0～33，中等力度 34～66，强力度 67～100。

添加剂、水量、消化时间、马桶不会使已命中的配方失效。配方唯一性通过内容校验，避免同一输入同时指向两个普通款。

先判定稀有，未中且命中配方时，目标占普通分支的 80%，其他普通款分配剩余 20%；选择益生菌则目标占普通分支的 100%。没有命中时，所有普通款按属性接近程度分配普通总预算，仍然允许自由混搭。

## 四、稀有概率直接算

每轮稀有基础合计 **2%**，没有食物、饮料、水量、马桶、力度或来源标签门槛。10 款稀有基准均分，即每款基础 **0.2%**。

稀有功能添加剂只增加其明确对应的款式。单个功能剂的加成合计 **＋3 个百分点**；对应多个稀有款时，在其目标中均分。例如一个功能剂对应两款，则每款增加 1.5 个百分点。选择这类功能剂后，稀有合计变为 **5%**。

| 功能剂 | 对应稀有款 | 选择后每款的总体概率 |
| --- | --- | --- |
| 金箔碎片 | 黄金传说、黄金汁 | 各 1.7% |
| 晶体种子 | 晶簇收藏家 | 3.2% |
| 彩虹糖屑 | 七色同框、彩虹瀑布 | 各 1.7% |
| 弹弹凝胶 | Q 弹果冻 | 3.2% |
| 霜花盐 | 霜花小晶块 | 3.2% |
| 星尘 | 星尘小陨石、夜光小浮岛 | 各 1.7% |
| 琥珀树脂 | 琥珀时间胶囊 | 3.2% |

未被该功能剂指向的稀有款仍各占基础 0.2%。

```text
稀有合计 = 2% + 当前功能剂的 3 个百分点加成（若有）
命中配方：总体目标普通 98% × 80% = 78.4%
          总体其他普通 98% × 20% = 19.6%
加益生菌：总体目标普通 98% × 100% = 98%
加稀有剂：总体目标普通 95% × 80% = 76%
自由组合：普通合计 100% − 稀有合计
```

添加剂最多选一个；选益生菌时稀有仍为基础 2%；选稀有功能剂时普通分支为 95%，命中配方仍按条件 80% 分配，没有命中才按属性自由分配。本次不再增加另一层封顶或叠加规则。

不再使用“稀有总上限 0.5%”“有原料才有资格”“倍率 ×4 等于多少概率”等旧解释；也不再对普通个体按 35% 概率套上 `rareMaterial`。

## 五、添加剂与实际样式

| 功能类别 | 行为 |
| --- | --- |
| 稳定剂：益生菌、膳食纤维粉 | 稳定自由组合的物态；益生菌还把匹配配方的普通目标从条件 80% 提高到 100% |
| 装饰剂：闪粉、金箔、干花瓣等 | 直接叠在本次实际便便上，保留该款轮廓与分类；不要求先抽中另一个“装饰候选” |
| 稀有功能剂：金箔、晶体种子等 | 对指定稀有款增加明确的概率；有装饰职责的同时显示装饰 |

“金箔碎片落在普通软块上”和“抽出黄金传说”是两件可以区分的事：前者是外观叠层，后者是完整的稀有图鉴条目。

## 六、产出与图鉴

一次抽取直接选出完整便便条目，再装配食材印记、装饰、颜色和本次个体种子。每个品种只有一个固定 Bristol 分类；每次产出依旧保存独立个体。

图鉴右上角的“全部样式”只用于调试查看 56 款实际造型及大图，不增加发现记录。水样便应保留水滩、涟漪、拖尾、喷射等区别，软块和糊状各自保留边界完整与塌落涂抹的形态区别。

开始后力度指针持续往复，停止时锁定力度，约 400 ms 后揭晓。时间/马桶的切换不会造成概率预告与最终抽取出现另一层隐藏差异。

## 七、策划调参入口

- 调某个普通款“怎样稳定得到”：修改 [固定配方表](固定配方表.md) 对应的内容配置。
- 调自由混搭倾向：调整食品、饮料及便便的五项形态属性。
- 调某个稀有款的机会：修改功能剂对应的明确百分点，不通过候选权重反推。
- 调颜色、残留、闪粉或花瓣：修改外观参数，不改普通分支的条件 80% 或稀有基础 2%。

配方见 [stool-recipes.js](../src/content/stool-recipes.js)，概率常数见 [game.js](../src/config/game.js)，统一计算见 [outcome-pool.js](../src/game/outcome-pool.js)。本文与配方表应随实际规则一起更新；内容数量或效果改变后，重新生成其他内容清单，避免让旧文案覆盖当前规则。

## 开发附录：自由组合的可核对公式

下面只负责自由组合，或固定配方未中目标后的普通分支。它不重算已确定的目标 80%/100%，也不改变稀有 2%/5%。

所有属性限制在 1～7。水量修正为：750 mL 及以下，硬度加 1；2000 mL 及以上，硬度减 1；中间不变。

```text
硬度 = clamp（食品硬度 × 0.7 + 饮料硬度 × 0.3 + 水量修正 + 功能剂硬度修正）
凝聚 = clamp（食品凝聚 + 功能剂凝聚修正）
延展 = clamp（食品延展 + 功能剂延展修正）
颗粒 = clamp（食品颗粒 + 功能剂颗粒修正）
蓬松 = clamp（食品蓬松 + 饮料蓬松修正 + 功能剂蓬松修正）
```

对每款普通候选计算距离，排除固定配方已经占用预算的目标款：

```text
距离 =（2 + 稳定度）× |餐盘硬度 − 候选硬度|
     + |餐盘凝聚 − 候选凝聚| + |餐盘延展 − 候选延展|
     + |餐盘颗粒 − 候选颗粒| + |餐盘蓬松 − 候选蓬松|
     + 4 ×（1 − 所选食物与候选配方食物的交集数 / 并集数）
     + 饮料差异（相同为 0，不同为 1）
候选权重 = 1 /（1 + 距离）
```

取距离最近的 3 款，按上述权重归一化分配本分支的预算；同距离时按品种 ID 排序，结果可重复核对。稳定度默认 0，益生菌为 1，纤维粉为 2，含义只是让硬度接近程度更重要。纤维粉同时给凝聚加 1；只有益生菌能把匹配配方的普通目标稳定为 100%。

候选池按稀有、固定目标、其他普通的顺序组成一次抽签；数学上等价于“先判定稀有，未中后再按普通分支抽取”。外观变化另外取种子，不改已抽出的品种。

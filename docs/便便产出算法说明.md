# 便便产出算法说明

规则版本 **22**。采用用户确认的生成机制改进方案：来源和物态先过滤，配方相似度连续变化，自由组合有主结果，益生菌稳定所有合法组合。保留56款图鉴、46款普通与10款稀有、单一饮用量。V6.1理想配方与牛奶机制沿用版本21，本次同步12款图鉴的造型力度偏好及回归说明。

## 一轮的顺序

1. 选择1–3种食物、一种饮料、饮用量0–1250 mL、至多一种添加剂、消化阶段。
2. 随机阶段在开始时等概率锁定2/4/8，刷新不会重抽；后台预览为三个阶段最终分布的等权混合。
3. 停止时锁定力度，计算物态、来源、普通候选和主结果。力度不改变物态。
4. 先抽独立稀有预算，未中时按普通最终分布抽取；约400 ms揭晓。外观种子只变化个体表面。
5. 保存实际配方、规则版本、颜色、食材残留、装饰和种子；历史收藏保留原快照，不按新规则改写。

主界面在配方选定、力度摆动和锁定等待时仅显示输入与操作，不提前展示品种、物态预测、理想力度或概率；实际结果在揭晓时显示。图鉴和后台仍可主动查看配方与概率，以下计算规则不因展示调整而改变。

## 单一饮用量与物态

原拉条就是所选饮料的全部摄入量，范围0–1250 mL，分5段、每段250 mL，六个刻度，默认750 mL；没有额外清水或第二个容量字段。0 mL不计饮料的湿软偏置、染色、气泡、来源标签或相似度差异。已有个体保留实际历史饮用量，不按新上限改写。

```text
食物湿软值 = (4 − 当前食品软硬值) × 0.9 + 食材质地偏置
食物权重 = 当前影响强度 × (主食 ? 2 : 1)
foodBase = 食物湿软值的加权平均
waterBonus = clamp((饮用量 − 1300) / 1000, −1.1, +1)
drinkBonus = 饮料湿软偏置 × min(饮用量 / 1500, 5/3)
timeBonus = {2: +0.75, 4: 0, 8: −0.85}
additiveBonus = −添加剂软硬修正 × 0.5
S = foodBase + waterBonus + drinkBonus + timeBonus + additiveBonus + rapidIrritant
```

鲜牛奶湿软偏置由 +0.02 增强为 +0.50，仍然按所选牛奶的同一份实际摄入量折算。阶段2时，若摄入量大于0、所选饮料带有乳糖标签、唯一添加剂为辣酱，且餐盘含有至少一种软硬值不高于2且影响强度不小于5的主食，叠加 rapidIrritant = +0.40；其他情况为0。这个组合效果只用于游戏湿软指数，不新增玩家体质、额外水量或排便失败规则。

饮料偏置是额外游戏特性，水量只在基础水分项计算一次。没有新增物态随机微扰，也没有改写用户食品九项参数文件。

| S区间 | 普通物态 |
| --- | --- |
| ≤−2.30 | 1型硬颗粒 |
| −2.30～−1.45 | 2型结块条 |
| −1.45～−0.55 | 3型裂纹条 |
| −0.55～0.55 | 4型柔软条 |
| 0.55～1.30 | 5型完整软块 |
| 1.30～2.20 | 6型糊状 |
| >2.20 | 7型水样 |

除首行外，下界不包含，上界包含。V6.1的46条普通理想配方已按新湿软值校验；明天见喷射仍为第7型、汉堡＋金针菇、牛奶与强力度。

## 图鉴来源与基础候选

46款普通图鉴分别配置 `generation`，与 `recipes` 理想配方完全分开：

- `sources.foods`：必须实际选择的食物，全部满足。
- `sources.tags`：可由餐盘、饮料或添加剂提供的来源标签，全部满足。例如全谷物、花瓣、跳跳颗粒。
- `sources.pigment`：实际主色素须匹配；抽中图鉴不能强制创造颜色。
- `sources.additives`：必须选择的添加剂，受最多一种限制。
- `identity`：来源身份分组；`forceZone`：造型偏好。
- `base`：通用基础造型，来源条件必须为空。七型各至少保留一个，保证任意合法餐盘有普通候选。

金针菇、玉米、燕麦、黑芝麻款需要对应真实食物；绿、莓紫、奶白、墨黑、可可等身份需要真实主色；闪粉、金箔、银霜款需要对应添加剂。金箔芝麻卷还需要黑芝麻。花瓣与跳跳款允许食物或功能剂提供相应标签。

螺旋、弧形、木纹、软枕、云朵、泥堆、液摊、喷射等通用造型不要求复刻整套食物。原“土豆泥小堆”复用ID和美术，改名“绵软小泥堆”，明确其为通用泥状造型。第6型没有辣味或跳跳来源时，只有泥堆一个合法候选，普通分支自然100%。

## 配方相似度与两层概率

先排除来源不符或物态不符的普通图鉴。对剩余候选计算与理想配方的距离：

```text
身份距离 = 1.6 × (1 − 食物交集/并集)
         + 0.8 × 食物五项质地的平均归一化差
         + 饮料差异
         + 0.9 × |饮用量差| / 1500
         + 0.35 × |阶段湿软修正差| / 1.6
饮料相同：差异0
饮料不同：0.15 + 0.2×|湿软偏置差| + 0.05×|气泡差|
```

食物质地比较食品软硬、凝聚、延展、颗粒、蓬松，按现有影响强度合并，主食乘2。来源身份这一层不读取力度。

两层都采用反距离平方插值：距离越近的理想配方影响越大；在理想点上取其连续极限，不使用“匹配开关＋重新抽整个池”的断崖。每个理想锚点给本项80%，剩余仅给其他合法项。

1. **身份层**：按每个身份内最接近的配方计算身份预算。单造型身份的理想点分配80%给自身、20%给其他合法身份；多造型身份的理想点将变化保留在自身造型内。
2. **造型层**：在身份预算内加入与理想力度区间的距离，再插值分配造型；凝聚、延展、颗粒、蓬松既修正造型距离，也决定剩余概率的适配权重；造型距离乘以(6＋当前属性平均偏差)/(6＋理想配方属性平均偏差)，使理想锚点保持零距离，双候选时属性也能改变概率。所有造型都偏好同一力度时，扣除共同力度偏差，避免无意义地把概率摊散。

这种分层使力度可以调整造型，但不会调整金针菇、玉米或颜色等身份的总预算。候选只有一个时直接为100%；不会引入非法项来凑20%。普通分支归一化后，概率最高者为主结果；同概率按稳定ID排序，不依赖抽签或上一轮历史。

示例：白米饭＋清水、阶段4、中等力度，饮用量1000/1250 mL时，当前主结果“顺畅小能手”的普通概率约为77.0%/80%，同为第4型。这些是当前参数的实际计算值；65%～75%、45%～65%是校准参考，不是额外硬切档位。

## 益生菌与随机阶段

任何合法组合都先算主结果。使用唯一添加剂益生菌后，普通分支只保留这个主结果，概率100%；稀有预算不变，整局为98%。益生菌不创造颜色、残留或装饰，也不改变力度。

后台对随机阶段的预览是三档混合，所以可能显示不同主结果的综合概率；开始时抽定阶段后，在该阶段内稳产。主界面不展示这些预测。改变阶段或实际力度后，合法主结果可以相应改变。

## 独立稀有与概率口径

10款稀有每轮各0.2%，合计2%，不受普通来源和物态门槛限制。一个稀有增益剂给指定款共享额外3个百分点，稀有合计5%。

| 情况 | 普通分支目标 | 整局目标 |
| --- | ---: | ---: |
| 多候选理想配方 | 80% | 78.4% |
| 任意合法组合＋益生菌 | 100% | 98% |
| 多候选理想配方＋稀有功能剂 | 80% | 76% |
| 只有一个普通候选 | 100% | 98%，或功能剂下95% |

稀有主题配方只作展示，不成为资格条件。马桶只影响外观与评分。

## 颜色、残留与验证

颜色先按真实来源确定：食品色素强度及影响强度、饮料色素及饮用量、带色素标签的添加剂共同选择主色。力度不参与。颜色身份必须匹配这个主色；普通造型也继承真实主色，稀有保留其固定材质。

食材残留只来自当前选择；短阶段增加保留、长阶段减少。金针菇印记只在实际吃了金针菇时出现。添加物来自所选唯一添加剂，不能靠随机品种代替添加物。

回归入口：`tests/causal-generation.test.js`，实际18次输入保存在 `tests/fixtures/最近18次配方.js`。覆盖来源零概率、46款理想配方、基础候选、液体相邻档位、身份预算与力度分离、益生菌、随机阶段，以及固定种子批量抽取与预览概率一致。后台预览、条件查看和实际掉落共用 `outcome-pool.js`。

## V6.1 配方与牛奶测试样例

已将V6.1的46款普通与特别图鉴理想配方全部更新为单一饮料量，10款稀有主题同步建议食材与力度，但稀有仍是独立2%／5%预算，不受主题食材门槛限制。花瓣夹心条既可由鲜花饼提供花瓣来源，也可以选择干花瓣添加剂；推荐益生菌不成为图鉴硬来源条件。四款必须使用装饰剂的图鉴仍有各自来源门槛。

华莱士汉堡＋金针菇、鲜牛奶250 mL、神秘辣酱、消化阶段2的湿软指数约为2.272，确定普通物态是第7型；强力度偏向喷射造型，但不会改变湿软分型。换成同量牛奶但不使用辣酱时，湿软指数不会获得辣酱和联合作用加成，仍是第6型。提高牛奶偏置后，V6.1「奶油白软块」仍是第5型，「火山小辣椒」仍是第6型，「明天见喷射」仍是第7型。

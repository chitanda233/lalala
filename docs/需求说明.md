# 需求规格说明

版本：整理版 1.3。整理日期：2026-10-19。适用阶段：开发与正式内容筹备。产出规则以本日简化要求为准。

本文件从用户的连续对话整理要求，后发要求覆盖早先方案。具体名单、参数初值、概率阈值、模板数量等实现补充见 [自主补充的设计与实现](实现说明与待完善事项.md)，不混作用户逐项指定的规则。

## 1. 产品方向与模块

以食物配方影响便便的形态、外观与特殊产出，形成可反复尝试和收集的游戏。便便应是干净、有趣、值得收藏的风格化藏品。

模块按食物、饮料、添加剂、马桶、产出规则、便便个体/图鉴和开发 Admin 分开，便于以后维护正式内容。内容数据、计算规则和界面职责应可区分。

| 编号 | 用户要求                         | 验收标准                                                             |
| ---- | -------------------------------- | -------------------------------------------------------------------- |
| R-01 | 以最新需求为准                   | 日常开发直接维护当前模型，不并行保留新旧玩法和两版界面               |
| R-02 | 配方共同决定便便，并在便便上体现 | 食物主导形态，饮料主要影响物态与颜色，添加剂承担功能；结果可见对应印记、色泽或纹理 |
| R-03 | 每次便便都是独立个体             | 按图鉴品种去重，同款只留最新一次，再保留最近7个不同品种；不合并印记，累计次数与图鉴解锁不受清理影响 |
| R-04 | 按健康形态分类学归类             | 当前采用 Bristol 1～7 型；具体条目有固定结构，个体分类与可见形态相符 |

当前为固定结构模板候选与外观叠层的实现，不把“任意连续几何生成”视为已经完成。用户要求的是产出关系和独立个体，具体模板模型由实现选择。

用户已接受食物属性方案。当前采用九项 1～7 数值：软硬程度、凝聚度、延展性、颗粒感、形态保留度、染色能力、蓬松度、顺滑度、影响强度，另选色素。具体字段键和数值表见 [食物文档](食物配置.md)。食物名称与现实身体反应的联系属于游戏创作，不是现实医学规则。

初次要求找 30 种，之后要求香蕉、观音土和另外 20 种。香蕉已在原有清单中；后续多变量设计补充熟甜菜根、蒸土豆，当前 53 种是实现结果，不是用户逐项批准过的正式最终总量。

## 3. 饮料、添加剂与马桶

| 编号 | 用户要求                       | 验收标准                                               |
| ---- | ------------------------------ | ------------------------------------------------------ |
| R-14 | 食物、饮料、添加剂是不同子模块 | 数据和入口分开，能共同参与一份配方                     |
| R-15 | 马桶有不同种类                 | 点击中央马桶打开预览，箭头翻页，点击“蹲它”装备；未解锁按钮上方直接展示解锁条件和进度                                 |
| R-16 | 马桶保留装备外观和评分反馈 | 最新简化规则取消设备对产出概率的影响，不能暗中改变固定配方或稀有概率 |

饮料选一种；添加剂最多一种，可以不加。选益生菌就不能同时选其他功能剂。益生菌把任意合法组合的普通主结果稳定为100%；其他稳定剂控制物态。闪粉、金箔、花瓣等装饰直接叠在本次实际造型上，稀有功能剂增加对应稀有的明确概率。当前名单、三款初始马桶、解锁次数及具体装备能力为实现补充。完整内容见 [饮料](饮料配置.md)、[添加剂](添加剂配置.md)、[马桶](马桶配置.md)。

## 4. 消化时间与力度

| 编号 | 用户要求                                           | 验收标准                                                          |
| ---- | -------------------------------------------------- | ----------------------------------------------------------------- |
| R-17 | 右侧“时间”表示游戏消化阶段 | 提供 2、4、8、随机；影响物态与配方，随机开始时锁定；不增加揭晓等待 |
| R-18 | 概率规则清楚、可控 | 最新简化要求覆盖旧的消化档位形态偏移，不能继续叠加隐藏修正 |
| R-19 | 开始拉屎后才启动往复指针                           | 空闲时不摆动；左侧力度低，右侧力度高，持续往返                    |
| R-20 | 玩家再次点击停止，按锁定的力度区间取代出场方式选择 | 不再提供旧“拉屎出场方式/节奏”下拉选项，实际力度影响规则           |
| R-21 | 锁定后快出结果，按钮别跳动                         | 提示和指针显隐不改变开始/停止按钮的位置；当前实现为约 400 ms 揭晓 |

往复 3 秒周期、0～100 和三段力度阈值为实现选择：轻力度 0～33，中等力度 34～66，强力度 67～100。固定配方直接匹配力度区间，不再另套力度指数倍率。2/4/8 仍是游戏档位，没有标成现实小时。规则见 [算法说明](便便产出算法说明.md)。

## 5. 便便、图鉴与描述

| 编号 | 用户要求                                       | 验收标准                                                                   |
| ---- | ---------------------------------------------- | -------------------------------------------------------------------------- |
| R-22 | 图鉴直接按分类学分类，再加“全部”               | 入口为全部和七型，不再用食物来源作为主分类                                 |
| R-23 | 未解锁/未发现便便统一虚影                      | 不直接露出真实图片，不靠真实轮廓或材质提前透露具体藏品                     |
| R-24 | 稀有款每轮都有机会 | 每轮先抽稀有，默认合计 2%；10 款均可出现，无原料门槛；功能剂对对应目标合计增加 3 个百分点 |
| R-25 | 稀有产出有不同呈现                             | 稀有材质有相应结果演出，且不改变已经确定的结果                             |
| R-26 | 大便描述是对形态的诊断                         | 描述软硬、成形、轮廓、纹理、颜色和残留，玩家结果中不展开冗长来源与权重日志 |
| R-27 | 完美连续螺旋需要合理分类                       | 当前按柔软连续成形归入 4 型；螺旋作为造型而非另设一类                      |

原先便便品种固定为 **50 种**；2026-10-18 用户追加第 7 型 6 种后，当前为 **56 种**。每种只有一个图鉴条目和一个固定健康形态分类，不允许按七型展开出额外品种。颜色、食材印记和同款多次产出的独立个体都不增加品种数。见 [便便文档](便便图鉴配置.md)。

其中46款普通款各有理想配方和独立来源条件。先过滤来源与物态，再用连续相似度计算身份和造型；力度只进入造型层。完整理想配方通常有普通分支80%的目标概率，偏离后逐步变化；独候选为100%。所有合法组合都确定主结果，益生菌稳定其普通分支100%。每轮基础稀有2%，对应功能剂后5%；通常理想配方整体78.4%，益生菌98%，稀有增益剂下理想目标76%。图鉴来源页和后台可检查必需来源，明天见喷射继续保留原第7型及食物／饮料／力度组合。全部配方见[固定配方表](固定配方表.md)。

每款统一定义硬度、凝聚、延展、颗粒、蓬松五项 1～7 属性。新规则使用食物、所选饮料的饮用量、饮料偏置、阶段和添加剂的湿软指数 S；先确定普通物态，再在型内按力度与属性距离分配。饮用量范围0–1250 mL，分5段、每段250 mL，0 mL不计饮料效果；固定配方同步校准。饮用量与阶段进入固定配方，随机阶段在开始时锁定并保存，后台预览为三档综合分布，主界面不提前显示结果。旧的 0.5% 稀有封顶、原料资格门槛、35% 材质涂层与多层指数权重全部取消。

图鉴右上角提供“全部样式”勾选开关，开启后可查看所有真实造型和大图，便于调试；不增加收藏记录。液态款需要水滩、飞滴、拖尾、涟漪、高压喷溅等不同轮廓，软块与糊状分别体现完整块体与塌落抹开。

## 6. 统一美术

用户上传《便便收藏游戏_统一美术风格提示词.md》，并要求便便形态符合这份参考。项目内保留于 [统一美术风格.md](统一美术风格.md)。

采用的视觉要求：风格化 3D、软陶玩具/幻想藏品质感、圆润清爽、统一轻俯视展示与柔和灯光；不强行所有便便都用尖顶螺旋；七型轮廓有区别；默认无五官、无写实污物和生理细节。食材印记也以干净、设计化的方式表现。

2026-10-18 用户进一步提供第 7 型截图与工程“新形态/”原图，要求以其轮廓、材质处理正式图片，并给其他形态做类似风格化。新版优先保留液摊、金液薄片、虹彩水冠、银河液面与墨汁水柱的具体结构，使用透明底；其他类型借用材质时保留本类型结构。当前处理范围与预览见 [新形态图片处理说明](新形态图片处理说明.md)。

资料中的五档品质、可旋转查看、具体生成器建议和示例品种是参考内容，并不自动成为全部必须实现的功能。当前是三档数值稀有度和静态素材叠层，差异在 [实现记录](实现说明与待完善事项.md) 明确说明。

## 9. 当前验收方式与待定事项

按“选食物 → 配饮料与添加剂 → 时间/装备 → 开始 → 往复指针 → 停止 → 快速结果 → 图鉴个体 → 刷新恢复”的完整路径验收，覆盖解锁、未发现隐藏和稀有表现；检查单屏完整性与按钮位置。

验证应核对完整配方的候选概率、未中稀有后的条件 80% / 益生菌 100%、稀有 2% / 功能剂后 5%、装饰门槛与可见叠层、饮用量与阶段的物态变化、随机阶段的等权预告与锁定存档。马桶不改变概率。历史通过数不作为本轮验收结论；仍需注意管理员将金针菇保留度调成1时的边界、正式解锁和试玩平衡。完整列表见 [实现差距与后续决定](实现说明与待完善事项.md#需要明确的边界与后续决定)。

## 10. 阅读舒适度补充（最新要求）

用户明确反馈整体 UI 与字体太小、留白太多、阅读费力。所有主要游戏界面应提高字号和文字对比度，放大主要卡片和插图，收紧无效空白；继续遵守手机单屏操作及按钮固定。具体字号层级、双列卡片与按高度分页属于实现选择，见 [手机交互规范](手机界面规范.md)。

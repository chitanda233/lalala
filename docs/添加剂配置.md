# 添加剂配置

> 本文件由 [内容文档生成器](../scripts/generate-content-docs.mjs)读取当前源码生成。规则版本 24，存档版本 7。

食物、所选饮料及饮用量、添加剂决定物态与来源身份。消化时间已移除，力度保留同身份内造型影响，不改变物态或来源身份预算。先按真实来源与湿软物态筛选，再按食物品类、标签和结构属性分配，推荐搭配没有固定命中奖励。力度在身份组内调整造型倾向。存在来源主题与通用造型时，主题合计占普通分支 **70%**，通用造型占其余部分；每组 **25%** 均匀分配，其余按倾向加权，任意合法搭配都能获得对应结果。益生菌将当前普通主结果稳定为100%。

未配置关联稀有组时，全体稀有均分基础 **2%**；有有效关联组时，仅该组均分 **20%**，组外稀有为0。统一概率池抽一次结果。添加剂至多一种。完整规则见 [便便产出算法说明](便便产出算法说明.md)，示例见 [推荐配方表](固定配方表.md)。

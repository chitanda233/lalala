# 添加剂配置

> 本文件由 [内容文档生成器](../scripts/generate-content-docs.mjs)读取当前源码生成。规则版本 23，存档版本 7。

未配置关联稀有组时，全体稀有均分基础 **2%**。选择配置了关联组的添加剂时，该组共享 **20%**，组内平均分配，组外稀有概率为0，普通分支占80%。使用同一份最终分布抽一次结果，不叠加第二次稀有抽签。

理想配方在普通分支通常占 **80%**，独候选自然100%；益生菌对所有合法组合的普通主结果稳定至 **100%**。无关联组时，理想配方与益生菌整局概率为 **78.4% / 98%**；有组时，普通理想目标整局为 **64%**。添加剂最多 1 种，可不加。

实际物态由食物、饮料摄入量和消化阶段共同决定；力度与食物结构影响同型子类。视觉／材质剂只叠加效果，明确标记为功能型的添加剂才可额外改变物态或普通选型。稀有按用户补充确认保留自身固定造型。

完整规则见 [便便产出算法说明](便便产出算法说明.md)，普通款理想配方见 [固定配方表](固定配方表.md)。

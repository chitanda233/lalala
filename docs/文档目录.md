## 当前概率与职责口径（规则23）

来源与物态先核验，普通理想配方为连续相似度锚点，益生菌稳定当前普通主结果。没有关联稀有组时，全体稀有均分基础2%，通常普通理想目标整局78.4%、益生菌98%。

存在添加剂关联组时，该组共享20%、平均分配，组外稀有0、普通80%，通常普通理想目标整局64%。读取每款添加剂的关联配置，金箔只是示例；任意有效目标数量和未来扩充的稀有品种均使用同一机制。稀有按用户补充确认保留各自固定造型。

只有明确启用功能的添加剂才参与物态或普通选型，其余只提供表面材质、装饰和关联组增益。旧的额外3个百分点、稀有总5%以及牛奶＋辣酱隐藏联动已被替代。细节见设计共识、算法与配置文档。

## 文档来源与更新

“用户要求”表示对话明确提出或接受的方向；“实现选择”表示为落实玩法所定的名单、阈值和技术方案；“待完善”表示尚未定稿的内容或当前边界。内容表记录实际源码，不追溯每个数值的修改人，也不把既有实现自动当作用户逐项确认。

面向阅读的文档均使用中文文件名。`README.md` 与 `AGENTS.md` 仅保留工具自动识别入口。

食物、饮料、添加剂、便便、马桶及固定配方表六份文档由脚本读取源码生成：

```sh
node scripts/generate-content-docs.mjs
node scripts/generate-content-docs.mjs --check
```

生成器不修改食物调参或玩家存档。算法说明、固定配方表、需求及协作约定需随实际规则一起维护。验证结果以当轮执行记录为准，不用历史通过数替代重构后的验收。

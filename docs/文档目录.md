## 当前代码的历史概率口径（需按设计共识重新审查）

以下描述的是现有／历史实现的概率行为，不代表本次确认的目标设计。目标规则见 [大便生成系统设计共识与实现交接](大便生成系统设计共识与实现交接.md)，尤其是对应添加剂将关联稀有图鉴组的共享目标概率提高到 20% 的规则。

来源与物态先核验，理想配方是连续相似度锚点，偏离后概率逐步变化；所有合法组合都有主结果。普通款通常可不加添加剂；四款装饰便便需指定材料。默认先抽合计 2% 稀有，未中后配方目标占普通分支 80%，总体 78.4%；任意合法组合选益生菌后普通分支主结果为100%，总体 98%。单选稀有功能剂时稀有合计 5%，普通条件概率仍为 80%，整局目标 76%。

旧资料中的 0.5% 稀有封顶、稀有原料资格门槛、35% 材质涂层和马桶概率倍率已被替代。消化阶段现在影响普通物态与配方，但不改变稀有预算。阅读概率时以最新算法、固定配方表与版本 19 源码为准。

## 文档来源与更新

“用户要求”表示对话明确提出或接受的方向；“实现选择”表示为落实玩法所定的名单、阈值和技术方案；“待完善”表示尚未定稿的内容或当前边界。内容表记录实际源码，不追溯每个数值的修改人，也不把既有实现自动当作用户逐项确认。

面向阅读的文档均使用中文文件名。`README.md` 与 `AGENTS.md` 仅保留工具自动识别入口。

食物、饮料、添加剂、便便、马桶及固定配方表六份文档由脚本读取源码生成：

```sh
node scripts/generate-content-docs.mjs
node scripts/generate-content-docs.mjs --check
```

生成器不修改食物调参或玩家存档。算法说明、固定配方表、需求及协作约定需随实际规则一起维护。验证结果以当轮执行记录为准，不用历史通过数替代重构后的验收。

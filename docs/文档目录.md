## 当前概率与职责口径（规则24）

食物、饮料与饮用量、添加剂共同决定产出。消化时间入口与影响已移除，力度在同型同身份内调整造型概率，不改变身份总预算。46款普通推荐与10款主题搭配按无时间的新水量公式校准，推荐是探索示例，不是精确开关或80%命中锚点。

普通候选先核验真实来源与实际物态，再按推荐食物的品类（60%）／标签（40%）相似度和五项结构偏差评分。带来源要求的普通主题候选与通用候选并存时，普通预算按70%／30%分配；每层25%均匀保底、75%按权重分配。益生菌稳定实际普通主结果。

没有关联稀有组时，全体稀有均分基础2%，普通合计98%；益生菌使实际普通主结果整局为98%。存在有效关联组时，该组共享20%、平均分配，组外稀有0、普通合计80%。读取每款添加剂的关联配置，任意有效目标数量均使用同一机制；稀有保留各自固定造型。普通与稀有合成统一池，仅抽取一次。

只有明确启用功能的添加剂才参与物态或普通选型，其余只提供表面材质、装饰和关联组增益。细节以现行算法与生成配置文档为准；历史原稿不覆盖新规则。

## 文档来源与更新

“用户要求”表示对话明确提出或接受的方向；“实现选择”表示为落实玩法所定的名单、阈值和技术方案；“待完善”表示尚未定稿的内容或当前边界。内容表记录实际源码，不追溯每个数值的修改人，也不把既有实现自动当作用户逐项确认。

面向阅读的文档均使用中文文件名。`README.md` 与 `AGENTS.md` 仅保留工具自动识别入口。

食物、饮料、添加剂、便便、马桶及固定配方表六份文档由脚本读取源码生成：

```sh
node scripts/generate-content-docs.mjs
node scripts/generate-content-docs.mjs --check
```

生成器不修改食物调参或玩家存档。算法说明、固定配方表、需求及协作约定需随实际规则一起维护。验证结果以当轮执行记录为准，不用历史通过数替代重构后的验收。

# 食物配置

先抽基础 **2%** 的稀有款；未中稀有时，理想配方默认 **80%** 出目标，只有一个合法候选时普通分支自然为100%。偏离理想配方后概率平滑变化；益生菌对所有合法组合的普通主结果都稳定至 **100%**。通常的理想配方与益生菌整局概率分别为 **78.4% / 98%**。

添加剂最多 1 种，也可不加。稀有功能剂给对应款合计增加 3% 的概率，使当轮稀有合计为 **5%**；因为不能与益生菌同选，此时多候选理想配方每轮实际目标概率为 **76%**。

完整规则见 [便便产出算法说明](便便产出算法说明.md)，46 条普通款配方见 [固定配方表](固定配方表.md)。

## 食物负责什么

餐盘最多三种不同食物。食物湿软值由现有软硬旋钮与食材偏置映射；按影响强度加权，主食额外乘2。再叠加饮用量、饮料特效、消化阶段与添加剂得到湿软指数 S，先确定物态，再在型内匹配造型。凝聚、延展、颗粒和蓬松仍使用原九项参数。食物与其质地、饮料及饮用量、阶段构成连续配方相似度；实际物态和图鉴来源条件先做硬过滤，力度只在同身份内调整造型。

用户在后台保存的九项属性数值保持原样。新增熟甜菜根、蒸土豆的默认参数单独写在食物定义中；已有参数文件下次保存前由后台读取默认值，不覆盖旧数值。

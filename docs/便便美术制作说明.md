# 便便藏品美术制作说明

2026-10-18 新版以用户截图及工程“新形态/”中的图片为轮廓、材质参考。完整素材对应与提示词见 [新形态图片处理说明](新形态图片处理说明.md)。

## 当前素材

全图鉴仍为 56 款、每款固定归入一种 Bristol 类型。19 款使用独立的 1254 × 1254 透明 PNG，覆盖六款新增第 7 型、基础液摊/喷射/落滴、连续弯条、结块、裂纹、软块、糊状、螺旋、黄金、果冻、陨石与石塔。它们位于 assets/stools/reference-v2/，映射由 src/content/stool-art-assets.js 维护。原六格低清 WebP 图集已退出运行时引用。

其余 37 款保留各自几何与食材纹样，使用统一调整的树脂光照：更大的主体、清楚的明暗、大块棚灯反射与轻接触阴影；硬颗粒、软块稍有有机起伏，稠糊反射比水样液体柔和。开发期渲染器仍输出原 50 款主体、装饰、金针菇三层及七型兜底，共 164 张 320 × 320 PNG。被高清图替代的旧层保留作兼容类型和制作参考；生成器不会覆盖 reference-v2/。

## 轮廓与材质

- 1 型颗粒：分散硬粒；陨石款为六颗独立棱面岩块，不能改成连续螺旋。
- 2 型结块：结块相连成短条或明确堆叠的石塔，保留连接与分节。
- 3 型裂纹：连续成条，裂纹为浅表凹槽。
- 4 型成形：完整弯条、长绳、折带与连续螺旋；棕色螺旋和实心金卷分别保留树脂、金属质感。
- 5 型软块：边缘完整，块与块之间留白；果冻参考青柠透明细闪材质，仍为分离软块。
- 6 型糊状：厚心塌落、薄边抹开，外缘参差或碎瓣相连。不能用四颗软枕头代替。
- 7 型水样：静止薄液摊、落滴空心涟漪、定向扇形高压喷溅、拖尾液流、竖向墨汁喷泉；飞滴与薄液片属于液体变形。黄金汁为整片流动黄金，彩虹瀑布为连续虹彩水冠，闪粉银河为深色折叠液面及细银紫闪点。

不加五官、厕所场景或脏污微观组织。参考图中与本类型结构不符的造型，只借用材质，不照搬轮廓。

## 运行时叠层

游戏通过 characterSvg 包装本地 PNG，无实时 WebGL 或远程图片依赖。参考图采用真实透明度遮罩，颗粒、气孔、食物残留、闪粉/金箔/花瓣等功能剂与金针菇印记都裁切在主体表面。每个实例使用独立遮罩 ID，避免多卡片互相污染。参考图的金针菇附加印记借用同类型的透明纹样层，再按新主体裁切；原生渲染款则共享几何预渲染印记。

普通棕色参考图可按饮料换色；玉米黄色颗粒、墨色、黄金、虹彩、果冻、陨石等关键参考材质保留本图配色。新图已把主材质与固有装饰合成在一张透明图中，不能逐粒独立换色；功能添加剂仍可额外叠加。普通原生主体和装饰保持分层染色。

未发现条目仍为统一匿名灰色虚影。图鉴右上角“全部样式”允许调试查看真实样式和大图，不写入收藏。

## 制作与预览

先启动静态服务：

```sh
LALALA_PORT=4175 node server.mjs
```

打开 scripts/stool-art/新形态预览.html，可按第 7 型、基础形态、特殊材质、全部 56 款切换，支持大图前后翻页和暖白/纯白/深灰/透明格底色。

原生模型重新渲染：

```sh
node scripts/stool-art/generate.mjs
node scripts/stool-art/inspect.mjs
node scripts/stool-art/inspect.mjs --shapes
```

需要本地 Node.js、开发依赖与 Chrome；LALALA_CHROME 可指定浏览器路径。--prototype 渲染十款原生校样，--type=3 按类型渲染，--marks-only 仅重渲染印记。主体和装饰、印记应使用同一镜头重新生成。高清参考图通过内置 image_gen.imagegen 单张处理；完整提示词与原始文件映射保存在 scripts/stool-art/新形态处理提示词.json。

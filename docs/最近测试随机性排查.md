# 最近测试随机性排查

> 历史排查记录。现行规则已更新至23，18次实际输入纳入自动回归；现行机制见[算法说明](便便产出算法说明.md)。以下保留当时数据和结论，不代表修复后的概率。

检查日期：2026-10-18。来源：当前浏览器 `lalala-dev` 游戏存档，检查个体 #025–#042，共18次。只读检查，没有修改或新增游戏个体。

## 结论

当前自由组合的候选池过宽，且固定配方匹配采用所有字段精确相等。任何字段偏离固定配方后，普通产出全部进入同型加权随机池；益生菌只在精确匹配时提供100%的普通分支保证，因此在这组实验中完全没有稳定效果。

这18次均由规则版本17产生。版本18只补上金针菇两款的来源限制；这些第5型候选在17与18下相同。下列概率由当前源码回算，可用同一实际配方复现，不是对随机数是否公平的统计证明。

## 候选池为何显得像抽签

以下为益生菌实验的整局概率；余下2%为10款稀有。实际力度按三档计算，同档内结果概率相同。

| 候选 | 轻力度14 | 中等力度39 | 强力度88 |
| --- | ---: | ---: | ---: |
| 软软小枕头 | 62.74% | 29.28% | 23.32% |
| 轻盈小云朵 | 11.63% | 8.15% | 8.31% |
| 莓紫软团 | 7.31% | 19.37% | 16.87% |
| 醒神咖啡豆 | 6.78% | 17.62% | 15.64% |
| 奶油白软块 | 6.78% | 17.62% | 15.64% |
| 玉米粒点名 | 2.76% | 5.95% | 18.23% |

问题有三层：

1. **精确配方失配后失去主结果。** 单个量、饮料或阶段不同，就从80%/100%分支切换为全部普通预算参与加权随机。
2. **候选缺乏完整来源约束。** 没有玉米仍可抽到玉米款；莓紫、奶白等带明确颜色或食材身份的品种也参与同型抽取。只补金针菇门槛尚未解决这一类问题。
3. **力度能显著改变无关候选权重。** 食物与物态相同，软枕从62.74%降至23.32%，玉米款从2.76%升至18.23%。这是现有配方距离公式的直接结果。

## 建议的调整方向

保留用户确认的稀有先抽、普通固定配方80%/益生菌100%规则。接下来需要统一处理食材、饮料颜色和添加物的来源门槛，并明确非固定组合的主结果及益生菌行为；避免普通自由池长期在多款不相关品种之间分散。这个方向会改变自由组合的产出规则，应与用户确认后再落地，不应只修改随机权重数字。

本次是排查，未改动生产算法、食品参数或浏览器存档。

# 固定配方表

更新日期：2026-10-18。规则版本 15。下表直接按本轮的真实内容配置整理，共 46 条普通配方，包含日常和特别点缀款；10 款稀有不设固定配方或原料门槛。

## 怎样使用

选择表中完整食物组合、对应饮料，再把力度停在指定档位，即匹配该款配方。食物顺序不影响匹配，多选或少选一种食物会使组合不匹配。饮用量、消化档位、马桶和添加剂不参与匹配。

每轮先抽 2% 稀有；未中时配方目标占普通分支 80%，所以默认总体命中率为 **78.4%**。添加剂可不选、最多选一种：选益生菌，普通分支目标稳定为 100%，总体 **98%**；选对应稀有功能剂，稀有合计变 5%，普通分支目标仍为 80%，总体 **76%**。

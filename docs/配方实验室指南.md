## 先用固定配方检查

固定配方由完整食物集合、饮料和力度档位组成，不要求添加剂。每轮先抽 2% 稀有，未中时目标普通款占普通分支 80%，总体命中 78.4%；选择益生菌后普通分支目标变 100%，总体命中 98%。添加剂单选，因此不能再同时加装饰剂或稀有功能剂。

| 组合例子 | 锁定力度 | 对应固定目标 |
| --- | --- | --- |
| 白米饭＋清水 | 轻 0～33 | 一气呵成螺旋 |
| 白米饭＋清水 | 中 34～66 | 顺畅小能手 |
| 白米饭＋清水 | 强 67～100 | 一镜到底长条 |
| 白米饭＋金针菇＋清水 | 中 34～66 | 明天见丝丝 |
| 华莱士汉堡＋鲜牛奶 | 轻 0～33 | 摊平小煎饼 |
| 华莱士汉堡＋鲜牛奶 | 强 67～100 | 喷射战士出击 |

食物少选或多选一项会使配方不匹配；摆放顺序不影响。水量、消化档位和马桶不改变固定配方。全部组合见 [固定配方表](固定配方表.md)。图鉴详情可在「形态」和「配方」之间切换；右上角「全部样式」可查看未发现造型，方便逐款核对。

## 再检查功能和自由组合

| 检查项 | 当前可观察的行为 |
| --- | --- |
| 益生菌 | 匹配配方的普通分支由 80% 稳定为 100%，仍有 2% 稀有 |
| 闪粉、金箔、干花瓣 | 装饰直接出现在实际产出上，保留原款轮廓 |
| 晶体种子 | 晶簇收藏家总体概率变 3.2%，其他稀有仍各 0.2%，合计 5% |
| 金箔碎片 | 黄金传说与黄金汁各 1.7%，其他稀有各 0.2%，合计 5%；并显示金箔装饰 |
| 膳食纤维粉 | 自由组合凝聚加 1，更重视软硬接近的普通款；固定配方仍为条件 80% |
| 金针菇 | 默认保留度下显示独立印记，不依赖抽中金针菇命名款 |
| 食品软硬、凝聚、延展、颗粒、蓬松 | 共同影响自由组合和普通落空结果，不重分已锁定的目标概率 |

稀有每轮均可出现，没有标签或来源资格门槛。没有命中固定配方时，按形态及食饮接近程度挑最近 3 款普通便便分配普通预算。食品主导形态，饮料主要影响物态和颜色；消化、马桶不改变产出概率。

完整规则与公式见 [算法说明](便便产出算法说明.md)，可视化比较见 [食物调参指南](食物调参指南.md)。

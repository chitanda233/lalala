## 1. 整体核心逻辑

配方须同时包含：**1–3种食物＋1种饮料的种类及容量＋额外清水量＋单选添加剂＋消化阶段＋力度**。食物决定干湿倾向、凝聚、延展、颗粒、蓬松、色素与保留印记；水和饮料总量共同影响物态；饮料种类在体积基础上提供风味效果、起泡、颜色；消化阶段模拟水分回收与残留；力度在已确定的布里斯托分类之内决定具体外形。不要让高力度凭空把石头变成喷泉。

**两个量不是一回事**：`额外清水量 W` 表示本轮另外喝了多少清水；`饮料量 V` 表示当前选定饮料实际喝了多少（可选择的饮料之一也叫「清水」）。两者都是真实选入的液体，**总液体 H = W+V**，不能把饮料里的清水再计第二遍。如果饮料是咖啡或西梅汁，V 仍然算液体，但饮料的特殊效果单独受 V 调节。前端同时展示 W、V 和 H，使玩家不会困惑。

| 控制项 | 推荐可选值 | 管理的维度 | 玩家应观察到什么 |
|---|---|---|---|
| 食物 | 1–3种 | 基础物态与残留、颜色、凝聚延展等 | 白吐司偏干；水果/西梅等在游戏里偏软；金针菇提供稳定可见残留 |
| 额外清水 W | 0 / 250 / 500 / 750 mL | 与 V 汇合决定液体背景，不单独决定稀有度 | 同餐加水，物态软化倾向逐渐上升；存在上限，不会任何餐都直接成为水样 |
| 饮料种类 | 当前11种中的1种 | 液体以外的特效 | 西梅汁偏软、汽水多泡、墨色与火龙果控制颜色；幻彩饮料不是基础款必需品 |
| 饮料容量 V | 150 / 300 / 500 mL | 本轮液体量及饮料特效强度 | 同种饮料量更多，软化/起泡/染色可更明显，但不同效果分别封顶 |
| 添加剂 | 单选一种（普通推荐益生菌） | 稳产／外观材质／稀有加成 | 益生菌保常规配方；闪粉、金箔等来自实际添加剂；不允许一轮选两剂 |
| 消化时间 | 2 / 4 / 8 / 随机（**游戏阶段**） | 干湿物态、食材保留 | 2代表较短、较湿、残留明显；4中性；8较长、较干、残留减少 |
| 力度 | 轻0–33／中34–66／强67–100 | 一型内部的空间形状 | 四型同样柔软时，轻卷、中条、强拉长；七型同样液态时，轻滩、中波纹、强喷射 |

时间 2/4/8 保留现有界面档位，但将其解释为**游戏内消化阶段**，而非「这顿饭真的在2小时内变成便便」。选择随机则等概率抽取2、4、8，并在本局开始时锁定和记录抽到的档位。具体档位数值为可调方案，不暗称医学结论。

## 2. 第一版可实际模拟的物态函数

避免「49个精确条件无机理」的硬编码。本稿提供透明、简单的游戏指数，并用它为全部46种普通结果及10种稀有主题组合做了一次静态一致性校验：

```text
foodBase = ∑(食物湿软偏置 × 食物权重) / ∑食物权重
  （主食谷物食物权重2，其余食物权重1；上线前从已有9项属性映射并调参）
H = W + V   // 不重复计饮料水分
waterBonus = clamp((H-700)/400 × 0.8, -1.1, +1.0)
drinkBonus = 饮料湿软偏置 × min(V/300, 1.667)
timeBonus = {2:+0.75, 4:0, 8:-0.85}
S = foodBase + waterBonus + drinkBonus + timeBonus + 添加剂物态修正

Bristol物态阈值（从干到湿）：
1型 S <= -2.30
2型 -2.30 < S <= -1.45
3型 -1.45 < S <= -0.55
4型 -0.55 < S <= +0.55
5型 +0.55 < S <= +1.30
6型 +1.30 < S <= +2.20
7型 S > +2.20
```

本次配方表默认先按无物态修正的益生菌/装饰剂计算；实际选择辣酱、植物油、纤维粉等修正时再叠加对应效果，勿把它们和益生菌同时选择。`drinkBonus` 的草案值：清水0、咖啡+0.20、西梅汁+0.60、鲜牛奶+0.02、气泡水+0.13；罕见饮料另行设定。饮料和饮水的软化效果有上限；咖啡不能在游戏里被错误设定为「一杯就让人严重脱水」。这份分数并不代表真实医学效果。

为检查配方物态，一些食物暂时使用的`foodBase`初值分别是：白米饭0、白吐司-0.95、糙米饭-0.70、原味燕麦粥+0.35、麻辣火锅+2.30、华莱士汉堡+2.00、梨+1.25、西梅+1.70。这些是草案模拟偏置，不是覆盖 `src/content/food-attribute-values.js` 的命令；正式实现应映射和尊重已有食物九项属性，并同步调整单项偏差。

除了 S，仍要单独计算凝聚、延展、颗粒、蓬松、染色和食材保留度。气泡饮料随 V 增大增加气孔但不能让七型水滩凭空变成有实体的五型云朵；颜色饱和度可随饮料量增加、随额外清水稀释，但金针菇等强保留印记不得因长时间全部消失。颜色、装饰的改变不能改变已确定的图鉴 ID。

| 白米饭＋清水 | 500 | 300 | 4 | +0.20 | 第4型 |
| 白米饭＋清水 | 750 | 500 | 2 | +1.75 | 第6型 |

另一个双变量示例：同样「糙米饭＋水煮蛋＋清水」，`W250/V150/T8`预测2型块状串；改成`W500/V300/T4`时会移向4型附近（实际本稿指数属于4型），而不是强行继续输出同一串硬石头。力度若不变，负责对当时物态执行对应的摆放效果，而不能逆转物态。

**核心可玩性**：让玩家通过加减水量、调整饮料量、切换2/4/8阶段，沿物态连续变化；再用力度雕琢造型；食物负责稳定的个性；特殊添加剂提供外部材质和可见特效。要让玩家可以推理，而不是机械记忆49个无关联数字。

## 7. 命中概率和偏离反馈：建议如何与既有规则并存

1. **保留原稀有预算**：无功能剂2%，有稀有剂5%。稀有先判定，不受W/V/T或力度变更影响，避免隐藏稀有倍率。稀有自己的材质和形态固定。
2. **完整匹配才能稳产**：普通/特别款精确匹配食物集合、饮料种类、饮料量V、额外清水W、消化阶段T、力度档位，并通过物态区间核验。普通款命中时，未中稀有的普通分支80%得到该款；如果本轮唯一添加剂为益生菌，100%得到该款，整体概率仍分别为78.4%与98%。这只是建议的v5新规则，不是现有v15实现。
3. **偏离要渐变**：离中心只差一格W/V或一档T时，不应从80%骤降到零。先按新的S、凝聚、延展等决定目前适配的类型；在同类型的候选中按参数距离分配，中心品种保留较高权重，偏差越大越容易移向另一型。完整中心点才保留80%/100%的明确概率；中间范围的具体百分比需要后续模拟调整，不在本稿捏造已实现的值。
4. **材质门槛必须统一**：闪粉、金箔、银霜、闪粉银河4款普通/特别藏品，需在固定目标和普通自由池中同时检查对应添加剂；添加剂单选，所以它们无法再带益生菌。闪粉等只给普通结果加可见特效；真正稀有仍用单独的特殊素材和登场特效。
5. **时间随机的公正**：选随机时必须先抽到实际2/4/8档，锁定进结果个体和首次发现记录，再根据同一档计算与展示概率。预告阶段应显示按2/4/8混合后的综合分布，不得偷偷拿4当默认。

## 8. 待落地边界与验收

- **先只改策划**：当前GitHub规则v15明确只让饮用量在自由组合中影响硬度±1，时间不参与概率；本稿建议W/V/T都进入固定配方，这是**实质性的机制变更**，必须修改匹配逻辑、自由分配、UI、概率预告、测试和自动生成文档，不能只替换配方表。
- **食物配置缺口**：熟甜菜根、蒸土豆尚未在现有51项列表里；需要新增后才能使用对应配方。本稿保留拟新增标记，没有声称可以直接运行。
- **明天见喷射冲突**：遵照已反馈的颗粒螺旋视觉，`enoki-jet` 暂拟改为4型「明天见颗粒螺旋」，与当前GitHub原7型不一致；落地时需调整分类、图鉴图、命名和测试。
- **磁石六块塔**：仍缺独立稀有品种及磁石立体吸附材质，本稿没有偷偷把普通石塔当磁石稀有。
- **医学边界**：2/4/8是游戏阶段；0、250、500、750毫升是游戏局内可选清水量，绝不是建议真实人体应当喝零水或用水控制排便的指导。布里斯托七型是形态描述，不能根据一顿饭精确预测现实排便；现实肠道转运可能经历数十小时。
- **验收建议**：逐款验证「对应S归属正确、46键唯一、改变W/V/T能重算S与类型、同物态的力只改姿态、益生菌仅常规稳产、稀有预算2%/5%不漂移、全部用游戏时间而非临床时间」，并做近邻输入的分布连续性测试。

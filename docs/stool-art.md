# 便便软陶藏品插画

以用户提供的 [统一美术风格 V1.0](art-direction.md) 为验收参考。全套使用同一个开发期 3D 渲染器：圆润软陶、树脂与幻想材质，统一轻俯视的 3/4 镜头、柔和主光和补光、接触阴影与轻微环境遮蔽。不添加五官、真实污渍、组织纹理、恶臭符号、厕所或人体。

## 已接入内容

50 种便便各有一个名称与固定分类的图鉴条目，分别输出主体、装饰和金针菇印记三张 320 × 320 透明 PNG；另有 7 组基础类型主体及印记兜底，共 164 张。素材位于 assets/stools/，游戏只加载实际展示的藏品及所需叠层。

1 型为分散圆润硬块；2 型为连接的结块条；3 型为带简化凹纹的连续条；4 型为光滑弯条，部分品种可以盘绕、折叠或呈螺旋；5 型为边缘完整的小软块；6 型为圆润松散团堆；7 型为平浅的不规则流体轮廓。保留七型区别，不统一套用尖顶造型。

黄金使用抛光金属反射；晶体与霜晶使用宽而克制的面光；彩虹使用连续色带；果冻为粉紫、半透明的软糖质感；夜光为紫色主体与青粉边缘；陨星为深蓝矿物和少量星点；琥珀为暖透明色与设计化叶纹。普通品种使用干净暖棕、奶咖、焦糖与协调的配方色。

主体和装饰分别输出，普通主体可以按餐盘与饮料染色，闪粉、金箔等装饰保持自己的颜色。例如蓝莓饮料的闪粉便便仍有紫色主体和独立亮点。稀有材质保留完整材质图。运行时由 SVG 容器包裹本地 PNG，并提供可访问名称；无需 WebGL 或远程服务。

未发现的藏品仅显示一份完全相同的匿名灰色虚影，不渲染其真实图片、名称、稀有度、材料或介绍。收集后才显示真实藏品。还未发现的类型示意图也采用虚影。

金针菇印记为浅奶油色的三根圆头细柄蘑菇纹样，按实际藏品和类型单独渲染，与主体共享几何、镜头和表面光照，严格落在模型表面。保留软陶玩具的干净风格，不加入写实食物残渣。印记叠在主体与普通装饰之上，保持独立颜色，黄金、晶体、彩虹、果冻等材质均可组合。

## 开发期重新渲染

需要本地 Node.js、项目开发依赖与 Chrome。先启动静态服务：

```sh
LALALA_PORT=4175 node server.mjs
```

另一个终端运行：

```sh
LALALA_CHROME="/path/to/chrome" node scripts/stool-art/generate.mjs
node scripts/stool-art/inspect.mjs
```

生成器通过开发期 WebGL 2 有符号距离场渲染球、椭球、连续管线与平浅流体形状，输出静态透明素材。普通和稀有共享几何，材质、装饰与印记分别计算。`--prototype` 只渲染十款校样，`--type=3` 可单独重渲染某一类型；`--marks-only` 仅重渲染印记；STOOL_ART_URL 可指向其他静态服务地址。

preview.html 展示藏品接触表，inspect.mjs 将其保存为 contact-sheet.png。所有插画只由项目代码与内容定义生成，不使用真实排泄物照片或网络图片。新增便便时需要补齐产出类型对应的素材并通过素材完整性检查。

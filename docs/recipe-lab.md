## 组合怎样体现

餐盘、饮料、饮用量、添加剂、消化档位、马桶和停止时的力度共同建立完整便便候选。选中具体条目后装配底色、食材印记、颗粒、气孔和个体种子，再按实际结构归类；不会另抽一次分类。

| 组合思路                             | 当前可观察的结果倾向                          | 边界                                                       |
| ------------------------------------ | --------------------------------------------- | ---------------------------------------------------------- |
| 熟香蕉                               | 偏软；可能有香蕉弯弯造型候选                  | 不必出香蕉形状，也不保证每次同型                           |
| 金针菇                               | 默认保留度 7，确定附加专属印记                | 独立于是否抽到“明天见丝丝”；可以叠加其他颜色和稀有材质     |
| 华莱士汉堡 + 神秘辣酱 + 强力度       | 更偏松散/水样，喷射候选可用                   | 仍按实际完整池抽取                                         |
| 蓝莓浓浆 + 闪粉                      | 蓝莓紫底色与独立反光点缀可共存                | 不等于稀有整块材质；闪粉属于特别点缀                       |
| 金箔乌龙 + 金箔碎片 + 黄金马桶       | 提高黄金权重，也提供碎金候选                  | 黄金依旧稀有，不是金箔越多越必出；黄金本身没有强制金箔门槛 |
| 晶簇矿泉液 + 晶体种子 + 水晶观测马桶 | 符合固定 3 型结构时有晶体候选并被加权         | 水晶马桶不能代替来源标签，最后仍需稀有抽取                 |
| 合适餐盘/水量 + 轻力度 + 涡流马桶    | 4 型连续螺旋更有机会                          | 螺旋要求轻力度，其他形态也可能产出                         |
| 观音土                               | 硬度与陶土浅灰色参与混搭，裂纹/结块候选被加权 | 以当前九项属性为准，不再重复加旧 effects 中的形态偏移      |

结果给出形态诊断，来源条件和权重用于开发说明。全部计算见 [算法说明报告](food-outcome-algorithm.md)，调参方式见 [Admin 指南](food-admin.md)。

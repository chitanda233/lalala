# 实现说明与待完善事项

更新日期：2026-10-19。规则版本23，存档版本6。以用户确认的生成机制改进方案及其后续答复为准。

## 已落实的规则

| 要求 | 实现 |
| --- | --- |
| 可预测的物态 | 单一饮用量0–1250 mL，5段、每段250；0 mL不计饮料效果；相同输入确定分型，不额外加入物态噪声，力度不参与S |
| 来源正确 | 46款普通图鉴配置独立来源规则；检查必需食物、标签、真实主色和添加剂 |
| 理想配方与来源分开 | 食物集合、饮料、饮用量、阶段用于相似度；只有定义图鉴身份的来源才是门槛 |
| 基础候选 | 默认七型各有无门槛base；手工修改导致缺失时提示，不能放开非法来源来兜底 |
| 自由组合有主结果 | 从合法最终分布取最高概率项；同概率按稳定ID确定，不依赖上次结果 |
| 理想概率80% | 以理想餐盘为反距离平方插值锚点；多候选时普通目标80%，独候选自然100% |
| 连续性 | 身份层不读力度；造型层加入力度距离，分层插值避免主结果切换时搬移整块保底 |
| 益生菌 | 所有合法组合的普通分支100%产出主结果，整局98%；不覆盖稀有 |
| 随机阶段 | 开始时抽定2/4/8并保存；后台预览按三档等权混合，阶段内益生菌稳定 |
| 稀有预算 | 无关联组时全体均分2%；有组时组内均分20%、组外0、普通80%，只从统一池抽一次 |
| 添加剂职责 | 视觉材质与功能显式区分，只有functional开启时参与物态和普通选型；特效写入独立个体 |
| 外观一致 | 先从真实来源确定主色；残留只取实际食物，装饰只取所选添加剂 |
| 预览与实际一致 | Admin预览、条件查看和掉落使用同一个最终候选池；主界面不显示预测结果或概率 |
| 可检查与调参 | 主界面保留输入和力度操作，结果揭晓时才显示；图鉴有配方与来源页，后台独立编辑来源、造型偏好与理想配方 |

## 数据与口径

56款图鉴ID和分类保留，普通46款、稀有10款。原土豆泥造型改名“绵软小泥堆”，明确其为第6型通用基础款；可可松露团与蜜糖琥珀条的理想配方补齐真实可可／暖蜜色来源。明天见喷射继续保留第7型、名称、配图与原汉堡＋金针菇／牛奶／强力度组合。

没有改写 `src/content/food-attribute-values.js`；食品九项旋钮仍直接影响计算。调整食品主色或软硬后，可能改变某个理想配方的来源或物态资格，须重新核验，不能强保旧结果。

通常理想配方整局78.4%，益生菌98%，有关联组的添加剂下理想目标64%；独候选时分别98%或80%。这些是实际最终概率，不能再把剩余预算加回主结果后仍称80%。

65%～75%、45%～65%为校准参考。当前米饭清水例子的邻档实际值约77.0%和80%；没有把参考区间写成隐藏硬切档。

## 验证与边界

- 来源缺失、真实主色不符时，对应普通图鉴概率必须为0；稀有不使用这些门槛。
- 46款理想配方逐一核验来源、物态和命中率，默认七型基础候选保证非空；手工配置造成空池时提示并取消本次生成，不增加次数。
- 玩家最近18次实际输入作为回归；缺来源的玉米、咖啡、奶白、莓紫款不再混入，益生菌稳定软软小枕头。
- 固定种子批量抽取检查理论分布、实际掉落与后台预览一致；历史收藏保持原快照，不作为新规则生成结果重新解释。
- 手机端验证揭晓前无结果与概率提示、益生菌、力度、刷新存档、图鉴来源和后台字段；不能据此声称完成Safari真机验证。

## 需要明确的边界与后续决定

1. 后续试玩可调整连续距离系数和造型偏好，但应以可复现输入与概率表比较，不能叠加隐藏倍率。
2. 再新增特殊食材或颜色身份时，必须配置来源、保留基础候选并提供可实现的理想配方。
3. 当前颜色取一个实际主色，不做复杂多色混合；虹彩等稀有材质维持独立美术。
4. 食物解锁、马桶解锁、音效、稀有演出节奏和正式发布平衡仍按各自任务推进。

# lalala

一个手机优先、单屏操作的配方与收集小游戏。中央马桶、固定开始按钮，食物/饮料/添加剂在左侧，消化时间在右侧，图鉴在右上角；大屏显示同一竖屏布局。

需求、各类完整内容和自主补充实现统一见 [项目文档目录](docs/README.md)。

## 启动

已安装 Node.js 22 的电脑上，双击 `启动游戏.cmd`，或在此目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。运行游戏不需要安装依赖，不需要账号，也不需要联网。

## 当前玩法

- 51 种食物：33 种初始开放，18 种按完成局数解锁。保留熟香蕉，加入观音土与另外 20 种风味、幻想食物。浮窗支持分类和分页，可查看介绍、属性与游戏影响，最多三种、不重复；支持增删、替换与取消草稿。幻想配料会单独标记。
- 20 种饮料：影响软硬、底色、气孔或特殊材质线索。调节当前饮料的总饮用量，范围 250–2,500 mL。
- 18 种添加剂：暂时全部开放，最多三种。闪粉、金箔、花瓣等提供点缀；晶种、凝胶等开启稀有候选。
- 10 种马桶：目前全部开放。材料、功能和姿态影响顺畅度、造型候选或稀有权重；场景外形随装备变化。
- 点击「开始拉屎」后显示往复指针，左侧力度低，右侧力度大；点击「停止」锁定 0–100 力度。0–33 为轻力度、34–66 为中等力度、67–100 为强力度，分别影响造型候选与形态权重。
- 停止后约 0.4 秒直接揭晓结果，不额外倒计时。指针摆动阶段不限时，不会自动停下；空格也可以开始或停止。开局后配置锁定。
- 50 种定型便便各自按布里斯托 1–7 型固定归档，另外附有基础、食物、色彩、力度、设备、点缀或稀有材质标签。已收集款展示插画、描述和配方线索；未发现款统一使用同一神秘剪影，收集后才显示真实名称、材质和详情。
- 底色与造型、点缀可叠加，例如蓝莓紫的闪粉便便。结算可展开「查看形态诊断」，观察实际产出的软硬、成形、表面纹理与可见残留；描述不再罗列详细配方来源。
- 食材可以给特定形态额外加权：熟香蕉偏向柔软 5 型，华莱士汉堡偏向 6–7 型。金针菇必定留下独立的蘑菇纹样，可叠加底色、点缀与稀有材质；印记随单局保存，并记录到已发现藏品。
- 黄金、晶体、彩虹、果冻、霜晶、夜光、陨星和琥珀共用稀有池，合计概率最高 **0.5%**。除黄金有极低基础机会外，其余需要对应原料；有原料也不保证产出。含碎金和整块黄金是两款不同收藏。
- 稀有款有专属登场文案、柔和光晕、材质纹样与一次粒子散开，八种材质分别配色，果冻有弹性入场；开启音效时播放对应短旋律。减少动态模式保留静态材质效果，操作无需等待动画结束。
- 配方、马桶、图鉴和进行中的单局自动保存在 localStorage。开始时保存餐盘与摆动起点；停止时保存力度、完整结果和揭晓时间。刷新不会重置摆动，也不会重新抽取已锁定结果。
- 消化时间有 2 / 4 / 8 / 随机四档：短时偏软、适中保持餐盘倾向、较久偏硬；与食物共同生成具体个体，不增加锁定后的等待。
- 游戏只维护 styles.css 一套布局，页面、选择器、图鉴与结果均不需要上下滚动，详见 [手机单屏交互](docs/mobile-ui.md)。
- 音效默认关闭，开启后使用浏览器合成音。

每种食物有软硬程度、凝聚、延展、颗粒、形态保留、染色、蓬松、顺滑和影响强度九项 1–7 级属性。软硬程度为 **1 非常软、7 非常硬**；图鉴的布里斯托分类仍为 **1 型硬颗粒、7 型水样**。混吃按影响强度合并，再结合饮料、水量、添加剂、马桶和力度生成完整便便，最后按自身结构归入七型；预告由同一候选池汇总。每次产出都是独立个体，保留自己的颜色、纹理与食材印记，图鉴可逐只查看。食材印记、颗粒、气孔和染色会显示在实际模型上，并随结果及图鉴保存。所有属性与配方效果均为游戏设定。视觉按干净、圆润的软陶玩具方向统一，50 个独立定型条目采用统一 3D 软陶渲染素材，生成流程见 [美术管线](docs/stool-art.md)；游戏无远程图片、字体或 CDN 运行依赖。

## 本地策划后台与发布

开发服务器启动后，打开 `/admin/`（当前为 http://127.0.0.1:4174/admin/）。后台支持 51 种食物分类筛选、九项属性与色素编辑、修改前后七型概率及造型预览、三食物搭配和保存到项目。参数写入 `src/content/food-attribute-values.js`；保存后刷新游戏，尚未生成结果的单局使用当前配置，已经锁定的结果按快照恢复。操作与属性说明见 [食物调参指南](docs/food-admin.md)。

```sh
npm run build
npm run preview
```

`dist/` 只包含游戏运行文件与确定的食物数据，排除 Admin 页面、管理接口、开发脚本和测试。正式分发使用这份目录；发布预览不提供后台或源码写入接口。

## 内容与模块

- [食物与便便产出算法说明报告](docs/food-outcome-algorithm.md)：九项参数、计算公式、完整标本生成与分类、稀有概率与完整演算案例。
- [食物模块指南](docs/foods.md)：51 种食物、参数、餐盘交互、幻想标记与解锁。
- [配方实验室内容手册](docs/recipe-lab.md)：20 种饮料、18 种添加剂、50 种便便、10 种马桶的完整清单与设计规则。
- [模块与内容指南](docs/architecture.md)：数据结构、效果叠加、概率、存档与扩展方式。

```text
src/
  config/       结果揭晓延迟、存档版本、内容数量限制
  content/      食物、饮料、添加剂、马桶、力度、七型、50 种定型便便与标本结构
  game/         属性、类型分布、底色、候选条件、概率、解释与单局
  progression/  食物解锁、图鉴发现、马桶拥有与装备
  storage/      当前数据校验、读写、跨标签页结算
  ui/           选择浮窗、场景、七型图鉴、结果、音效与 SVG
```

根目录 `app.js` 是浏览器入口，`bristol.js` 提供分类与插画的公共导出。`src/config/game.js` 集中配置规则版本、单局上限与锁定后的 400 ms 揭晓延迟；消化档位影响形态，已有单局按保存的配方与结果恢复。

## 检查

```sh
npm run check
npm install
npm test
```

可单独运行 `npm run test:unit` 和 `npm run test:e2e`。浏览器测试通过 `LALALA_CHROME` 指定 Chrome / Chromium 可执行文件。

形态定义参考 [Cleveland Clinic — Bristol Stool Chart](https://my.clevelandclinic.org/health/articles/bristol-stool-chart)。游戏映射不用于推断真实身体反应；数据、数值、文案与软陶藏品素材后续均可按模块替换。

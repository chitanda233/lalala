# lalala

一个关于配方、等待和放松的轻松小游戏。首版为独立网页原型，桌面和手机浏览器均可使用。

## 启动

已安装 Node.js 22 的电脑上，双击 `启动游戏.cmd`，或在此目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。运行游戏不需要安装依赖，不需要账号，也不需要联网。

## 当前玩法

- 左侧选择四种主要配方，调节 250–2,500 mL 饮水量，选择益生菌、咖啡和辣酱。
- 右侧选择 2 秒、4 秒、8 秒，或随机 2–8 秒；时间单位按测试阶段需求设为秒。
- 点击「开始拉屎」，或在未聚焦按钮/输入框时按空格。开始后配方锁定，倒计时结束自动结算。
- 共 8 种趣味角色外观；另按布里斯托大便分类法分为 1–7 型，结算插画随形态变化。
- 「我的图鉴」分为「布里斯托分类」和「角色收藏」，支持按偏硬（1–2 型）、成形（3–4 型）、偏稀（5–7 型）筛选，并保存发现过的角色与形态组合。原有角色收藏继续保留，旧存档的形态从下一局开始记录。
- 配方、图鉴和进行中的计时保存在浏览器 localStorage。刷新页面后，计时按真实经过的时间继续；后台放置也会正常结束。
- 音效默认关闭，手动开启后使用浏览器合成音，无外部音频素材。

视觉由原生 HTML / CSS / SVG 绘制。无远程图片、字体或 CDN 运行依赖。

## 形态分类

形态定义参考 [Cleveland Clinic — Bristol Stool Chart](https://my.clevelandclinic.org/health/articles/bristol-stool-chart)：1 型分散硬块；2 型结块的硬条；3 型表面开裂条状；4 型光滑柔软条状；5 型边缘清楚的软块；6 型边缘不规则的糊状碎块；7 型无固体的水样液体。全部插画为原创 SVG。

配方、水量、添加剂与类型之间的映射仅为可调整的游戏规则，不能用来推断真实身体反应。规则集中在 `bristol.js`。

## 检查

```sh
npm run check
npm install
npm test
```

端到端测试默认使用本机安装的 Chrome；可通过 `LALALA_CHROME` 环境变量指定其他 Chromium 可执行文件。

## 范围

目前是主界面与完整基础循环原型。配方效果均为游戏设定。分享链接在本次环境无法读取，玩法依据用户当前消息和「测试阶段用秒」的补充实现，后续可继续细化数值、图鉴和长期养成系统。
